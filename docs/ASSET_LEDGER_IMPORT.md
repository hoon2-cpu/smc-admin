# 자산장부 이관 가이드 (롯데렌탈 / AJ네트웍스 / 전체자산 → 플랫폼)

기존에 갖고 있던 **롯데렌탈장부 · AJ네트웍스장부 · 전체자산장부**를
자산관리 플랫폼이 연동된 구글시트로 옮기는 방법입니다.

## 핵심 원칙

- 플랫폼은 **오직 `2_자산등록기록` 시트 1개**만 자산 데이터로 읽습니다.
  → 3개 장부를 **이 한 시트에 모두 이어붙여** 넣습니다. (렌탈/구매는 `취득구분`·`렌탈사` 열로 구분)
- **1행은 헤더**, **2행부터 데이터**. 열 순서는 아래 표를 그대로 지켜야 합니다. (플랫폼이 열 위치로 읽음)
- 날짜는 **`YYYY-MM-DD`** 형식(예: 2024-05-20), 금액·렌탈료는 **숫자만**(콤마·"원" 없이).
- 원본 장부는 그대로 보관하고, **복사본을 붙여넣기** 하세요.

## 장부별 매핑 요령

### 1) 롯데렌탈장부 → 붙여넣기
- **P열 취득구분 = `렌탈`**, **Q열 렌탈사 = `롯데렌탈`** 로 채웁니다.
- 월 렌탈료 → W열, 계약기간 → X·Y열, (반납했으면) 반납일 → Z열.
- I열(구매금액)·S열(구매처)·T열(보증)은 비움.

### 2) AJ네트웍스장부 → 붙여넣기
- 위와 동일하되 **Q열 렌탈사 = `AJ네트웍스`**.

### 3) 전체자산장부(구매분) → 붙여넣기
- **P열 취득구분 = `구매`**, Q열 렌탈사는 비움.
- I열 구매금액·S열 구매처·T열 보증만료일을 채웁니다.
- W~Z(렌탈 열)는 비움.

> 세 장부의 행을 **2_자산등록기록 아래로 계속 이어붙이면** 됩니다. 시트를 나눌 필요 없습니다.

## 이관 순서 (권장)

1. 구글시트 `2_자산등록기록` 탭 열기 → **1행 헤더** 위 표대로 확인/작성.
2. 각 장부에서 **위 열 순서에 맞게 열을 재배열**한 뒤 값만 복사.
3. `2_자산등록기록`의 **2행부터 '값만 붙여넣기'**(Ctrl+Shift+V)로 서식 없이 붙여넣기.
4. 붙여넣은 뒤 확인:
   - L열 상태값이 5종 중 하나인지 (오타 시 대시보드 집계에서 빠짐)
   - P열이 `구매`/`렌탈`, 렌탈은 Q열 렌탈사(`롯데렌탈`/`AJ네트웍스`)가 정확한지
   - 날짜·금액 형식
5. 플랫폼 **자산관리 화면 새로고침** → 목록·대시보드 반영 확인.
   - 렌탈 월비용은 **반납일(Z)이 없고 폐기가 아닌** 렌탈 자산의 W열 합계로 집계됩니다.

## 주의

- **자산번호(B열)는 중복 금지.** 신규 등록분은 플랫폼이 `AST-YYYY-####`로 자동 부여하므로,
  과거 이관분도 겹치지 않게 하세요(예: 과거분은 `LEG-...` 접두어 사용 후 점진 정리 가능).
- 부서/위치 문자열은 **설정 → 부서(조직)/사용위치 관리**의 값과 되도록 일치시키면
  이후 드롭다운 선택·필터가 깔끔합니다. (다르면 자유 텍스트로 들어가며 표시는 됨)
- 이관 전 **테스트 행 몇 개로 먼저 붙여넣어 표시 확인** 후 전체 이관을 권장합니다.
